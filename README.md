# AIORI-3 Hackathon — CyberTrace

CyberTrace is an incident-response and evidence-ingestion application built
for the AIORI-3 hackathon. The project source, setup instructions, tests, and
deployment notes are in [`src/CyberTrace/`](src/CyberTrace/).

**Video presentation:** https://youtu.be/9I8wAPlaooQ?si=So0ub1TqRp7P7nhL

**Project presentation:** [Cyber Sentinels presentation (PDF)](Cyber_Sentinels_Presentation_A3-PS013-TC470.pdf)

The existing hackathon presentation and video link are retained in this
repository. For local development, testing, or hosting, start with the
[CyberTrace README](src/CyberTrace/README.md). A Render Blueprint is provided
at [`render.yaml`](render.yaml).
